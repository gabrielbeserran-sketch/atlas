# Termos de Uso — RASCUNHO

Este arquivo é um rascunho técnico e **não deve ser publicado sem revisão jurídica**.

Os termos finais devem cobrir escopo do serviço, responsabilidades, contas, disponibilidade, propriedade
intelectual, limites de recomendações automatizadas, obrigações do usuário, suporte, suspensão, encerramento,
proteção de dados e legislação aplicável.
