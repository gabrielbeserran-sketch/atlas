## Entrega
A fase adiciona pipelines, builds, ambientes, deployments, aprovações,
feature flags, checks de prontidão, rollback lógico, métricas de entrega,
dashboard Flutter, migração Alembic, testes estruturais e modelos de
GitHub Actions.

## Limites
Os pipelines são modelos configuráveis e arquivos de referência. Eles
precisam ser conectados ao repositório, segredos, infraestrutura e
provedor de hospedagem reais. A publicação automática não é executada
por este pacote.
