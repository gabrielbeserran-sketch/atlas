# Atlas — infraestrutura gratuita

A exigência de VPS/domínio pago foi removida.

A V1 passa a usar:
- Oracle Cloud Always Free;
- DuckDNS gratuito;
- Caddy/HTTPS;
- PostgreSQL;
- Redis;
- FastAPI;
- anexos e backups persistentes.

Foram adicionados scripts de:
- preparação do Ubuntu;
- Docker;
- firewall;
- atualização DuckDNS;
- geração de secrets;
- deploy;
- auditoria;
- validação Windows;
- gate final Android gratuito.
